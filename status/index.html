How each figure is counted: Documentation.

The canary is scheduled to run every 120 minutes; cycles that did not run (for example while our host was down) are not counted either way, so the figures cover the cycles that ran. Each cycle sends one fresh run of the Google Trends actor through the customer path (the same route a customer request takes, ending at the actor on Apify) on a rotating keyword with the cache bypassed. A run counts as clean only when it returns at least 40 weekly points on the 12-month window, ≥5 top and ≥1 rising related queries, in under 90 s; a partial answer counts as a failure.
